# Sharad Jha — Portfolio (Next.js + Tailwind)

This is a Next.js + TypeScript + Tailwind starter implementing a dark, developer-focused portfolio matching provided visual references.

Getting started:

```bash
npm install
npm run dev
```

Place your resume at `public/Sharad-Jha-Resume.pdf` and update `data/siteConfig.ts` with social links.

Deploy to Vercel as usual.
