## How It's Structured

All my portfolio content lives in `data/siteConfig.ts` — a single configuration file that includes:
- my profile and bio
- all my projects with descriptions and tech stacks
- my certifications
- my education background

This keeps things simple and makes it easy to update without touching component code.

## Running It Locally

If you want to fork this and build your own portfolio, or just run mine locally:

**Install dependencies:**
```bash
npm install
```

**Start the dev server:**
```bash
npm run dev
```

Then visit `http://localhost:3000`

**Build for production:**
```bash
npm run build
npm run start
```
